Capitolul 1

Introducere în C# și .NET

Bazele platformei, istoric, instalare și primul program „Hello World”

📦 Ce este .NET?

.NET (pronunțat „dot net”) este o platformă software gratuită și open-source, creată de Microsoft, care îți oferă tot ce ai nevoie pentru a construi și rula aplicații moderne. Este formată din trei componente principale:

  • Runtime-ul (.NET Runtime) – mediul în care rulează codul tău, gestionând memoria, securitatea și execuția.
  • Bibliotecile de clase (BCL) – o colecție uriașă de cod predefinit care îți oferă funcționalități gata de utilizare (lucru cu fișiere, rețea, criptare etc.).
  • Compilatorul – transformă codul tău C# într-un format intermediar (IL) pe care runtime-ul îl poate executa.

Platforma este cross-platform – poți rula aplicații .NET pe Windows, macOS și Linux. Există două „variante” principale: .NET Framework (doar pentru Windows, versiunea clasică, acum în mare parte înlocuită) și .NET (fostul .NET Core), care este varianta modernă și recomandată.

⚙️ Instalarea SDK-ului .NET

SDK (Software Development Kit) este setul de instrumente care include compilatorul C#, runtime-ul .NET și bibliotecile necesare pentru dezvoltare. Fără el, nu poți compila și rula cod C#.

  • Descărcare: Accesează site-ul oficial dotnet.microsoft.com și descarcă versiunea potrivită pentru sistemul tău (Windows, macOS, Linux).
  • Instalare: Urmează pașii asistentului de instalare. Pe Windows, poți folosi și installer-ul Visual Studio care include automat SDK-ul.
  • Verificare: După instalare, deschide un terminal (Command Prompt, PowerShell sau Terminal) și tastează dotnet --version. Dacă vezi un număr de versiune (ex: 8.0.100), totul e instalat corect!

👋 Primul program – „Hello World!”

Tradiția în programare spune că primul tău program trebuie să afișeze mesajul Hello World!. E cel mai simplu mod de a verifica că totul funcționează. Urmează acești pași:

  • 1. Creează un proiect nou: În terminal, navighează într-un folder dorit și tastează dotnet new console -n HelloWorld. Aceasta creează un folder numit „HelloWorld” cu un proiect C# minimal.
  • 2. Intră în folder: cd HelloWorld
  • 3. Rulează programul: dotnet run. Ar trebui să vezi în consolă textul: Hello, World!
  • 4. Explorează codul: Deschide fișierul Program.cs într-un editor. Vei vedea ceva de genul: Console.WriteLine("Hello, World!"); – aceasta este linia care afișează mesajul.

🎉 Felicitări! Ai scris și rulat primul tău program C#!

📁 Structura unei soluții C#

Când creezi un proiect C#, nu ai doar un singur fișier – ai o întreagă structură organizată care te ajută să-ți gestionezi codul. Iată cele mai importante elemente:

  • Fișierul .csproj – inima proiectului. Conține informații despre versiunea .NET folosită, pachetele externe (NuGet) și setările de compilare.
  • Program.cs – punctul de intrare al aplicației. Aici începe execuția codului tău (metoda Main sau instrucțiunile top-level statements).
  • Solution (.sln) – opțional, dar util când ai mai multe proiecte. O soluție grupează proiecte conexe (de exemplu, o aplicație web + o bibliotecă de clase).
  • Folderele – îți organizezi codul în foldere după logică (ex: Models/, Services/, Controllers/), păstrând proiectul curat și ușor de navigat.
