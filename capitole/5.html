Capitolul 5

OOP: Clase și obiecte

Fundamentele programării orientate pe obiecte în C#

Definirea unei clase

O clasă este un șablon care definește structura și comportamentul unui tip de date. O clasă conține câmpuri (date) și metode (funcții) care operează asupra acelor date. În C#, clasele sunt tipuri de referință.

// Definirea unei clase simple
class Persoana {
  // Câmpuri (date)
  public string Nume;
  public int Varsta;

  // Metodă (comportament)
  public void AfiseazaInfo() {
    Console.WriteLine($"Nume: {Nume}, Varsta: {Varsta}");
  }
}
  • Clasa este definită cu cuvântul cheie class urmat de numele clasei (convenție: PascalCase).
  • Câmpurile sunt variabile declarate în interiorul clasei, care stochează starea obiectului.
  • Metodele definesc acțiunile pe care le poate efectua un obiect de acel tip.
  • Modificatorii de acces (public, private) controlează cine poate accesa membrii clasei.

Crearea obiectelor

Un obiect este o instanță concretă a unei clase. Pentru a crea un obiect, se folosește operatorul new care alocă memorie și apelează constructorul clasei.

// Crearea unui obiect de tip Persoana
Persoana persoana1 = new Persoana();
persoana1.Nume = "Ana Popescu";
persoana1.Varsta = 30;
persoana1.AfiseazaInfo(); // Nume: Ana Popescu, Varsta: 30

// Crearea mai multor obiecte din aceeași clasă
Persoana persoana2 = new Persoana();
persoana2.Nume = "Ion Ionescu";
persoana2.Varsta = 25;
  • Operatorul new alocă memorie pe heap pentru noul obiect și returnează o referință către acesta.
  • Fiecare obiect are propria sa copie a câmpurilor, independentă de alte obiecte.
  • Accesul la membri se face prin operatorul punct (.): obiect.NumeMetoda().
  • Referințele multiple pot indica același obiect: modificările făcute printr-o referință sunt vizibile prin toate.

Constructori

Constructorul este o metodă specială apelată automat la crearea unui obiect. Are același nume cu clasa și nu returnează niciun tip (nici măcar void). Constructorii sunt folosiți pentru inițializarea membrilor.

class Persoana {
  public string Nume;
  public int Varsta;

  // Constructor implicit (fără parametri)
  public Persoana() {
    Nume = "Necunoscut";
    Varsta = 0;
  }

  // Constructor cu parametri
  public Persoana(string nume, int varsta) {
    Nume = nume;
    Varsta = varsta;
  }
}

// Utilizare constructori
Persoana p1 = new Persoana(); // Constructor implicit
Persoana p2 = new Persoana("Maria", 28); // Constructor cu parametri
  • Constructorul implicit este cel fără parametri; dacă nu definești niciun constructor, compilatorul generează unul automat.
  • Supraîncărcarea constructorilor permite definirea mai multor constructori cu parametri diferiți.
  • this se poate folosi pentru a apela un alt constructor din același constructor: public Persoana() : this("Necunoscut", 0) { }
  • Constructorul static este apelat o singură dată, la prima utilizare a clasei, și inițializează membrii statici.

Cuvintele cheie this și static

this este o referință către instanța curentă a clasei. static indică faptul că un membru aparține clasei în sine, nu unei instanțe particulare.

class Contor {
  // Câmp static (comun tuturor instanțelor)
  private static int numarTotalInstante = 0;

  // Câmp de instanță
  private int id;

  public Contor() {
    numarTotalInstante++;
    this.id = numarTotalInstante; // this diferențiază câmpul de parametru
  }

  // Metodă statică
  public static int GetNumarInstante() {
    return numarTotalInstante;
  }
}

// Apelare metodă statică – direct prin numele clasei
int total = Contor.GetNumarInstante();
  • this este util când parametrii au același nume cu câmpurile clasei, pentru a le diferenția.
  • this poate fi folosit și pentru a transmite instanța curentă ca parametru unei alte metode.
  • Membrii statici sunt partajați de toate instanțele clasei și se accesează prin numele clasei, nu printr-un obiect.
  • Metodele statice nu pot accesa membri de instanță (non-statici) direct, deoarece nu au o referință this.

Destructorul

Destructorul este o metodă specială apelată automat de Garbage Collector atunci când un obiect este colectat. În C#, destructorul este rar folosit explicit, deoarece memoria este gestionată automat.

class Resursa {
  // Destructorul – numele clasei precedat de ~
  ~Resursa() {
    // Cod pentru eliberarea resurselor unmanaged
    Console.WriteLine("Obiectul Resursa a fost distrus.");
  }
}

// Pattern-ul recomandat: IDisposable
class ResursaManaged : IDisposable {
  public void Dispose() {
    // Eliberare explicită a resurselor
    Console.WriteLine("Resurse eliberate explicit.");
  }
}

// Utilizare cu using (apelare automată Dispose)
using (ResursaManaged r = new ResursaManaged()) {
  // Folosire resursă
} // Dispose() este apelat automat aici
  • Destructorul nu poate fi apelat manual; este invocat automat de Garbage Collector la un moment nedeterminat.
  • Nu poate avea parametri și nu poate fi supraîncărcat; o clasă poate avea un singur destructor.
  • Pattern-ul IDisposable este metoda recomandată pentru eliberarea resurselor, oferind control explicit prin metoda Dispose().
  • Instrucțiunea using asigură apelarea automată a Dispose() la ieșirea din bloc, chiar și în caz de excepție.

Proprietăți auto-implementate

Proprietățile auto oferă o sintaxă concisă pentru a crea proprietăți fără a defini explicit un câmp privat. Compilatorul generează automat câmpul suport (backing field).

class Produs {
  // Proprietate auto cu get și set public
  public string Nume { get; set; }

  // Proprietate auto cu set privat
  public decimal Pret { get; private set; }

  // Proprietate read-only (doar get)
  public int Id { get; }

  public Produs(int id, string nume, decimal pret) {
    Id = id;
    Nume = nume;
    Pret = pret;
  }
}
  • Proprietățile auto simplifică codul când nu este nevoie de logică suplimentară în getter sau setter.
  • Set privat permite modificarea proprietății doar din interiorul clasei, oferind imutabilitate controlată.
  • Proprietățile read-only pot fi setate doar în constructor sau direct la declarare.
  • Inițializare directă: public string Nume { get; set; } = "Necunoscut";
