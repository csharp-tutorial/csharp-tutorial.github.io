Capitolul 7

Colecții și generice

Liste, dicționare, cozi, stive și tipuri generice

Introducere în colecții

Colecțiile sunt structuri de date care permit stocarea și gestionarea mai multor elemente. Spre deosebire de array-uri, colecțiile au dimensiune dinamică și oferă metode avansate pentru adăugare, eliminare, căutare și sortare. În C#, există două categorii principale: colecții non-generice (vechi, din System.Collections) și colecții generice (moderne, din System.Collections.Generic).

// Spațiul de nume necesar pentru colecții generice
using System.Collections.Generic;

// Comparație: array vs colecție
int[] array = new int[3]; // Dimensiune fixă
List<int> lista = new List<int>(); // Dimensiune dinamică
  • Colecțiile generice oferă siguranța tipurilor la compilare și performanță mai bună decât cele non-generice.
  • Principalele colecții generice: List<T>, Dictionary<TKey,TValue>, Queue<T>, Stack<T>, HashSet<T>.
  • Toate colecțiile implementează IEnumerable<T>, permițând iterația cu foreach.
  • Colecțiile non-generice (ArrayList, Hashtable) stochează elemente ca object, necesitând cast și având risc de erori la runtime.

List<T>

List<T> este o colecție indexată, cu dimensiune dinamică, similară unui array dar mult mai flexibilă. Permite adăugarea, eliminarea, inserarea și căutarea elementelor folosind metode dedicate.

// Crearea și popularea unei liste
List<string> fructe = new List<string>();

// Adăugare elemente
fructe.Add("Mar");
fructe.Add("Banana");
fructe.Add("Portocala");

// Inserare la o poziție specifică
fructe.Insert(1, "Para");

// Eliminare
fructe.Remove("Banana");  // După valoare
fructe.RemoveAt(0);        // După index

// Accesare elemente
string primulFruct = fructe[0];
int numarFructe = fructe.Count;

// Căutare
bool exista = fructe.Contains("Mar");
int index = fructe.IndexOf("Portocala");
  • Add() adaugă la sfârșitul listei; Insert() adaugă la un index specific, deplasând elementele existente.
  • Remove() elimină prima apariție a unei valori; RemoveAt() elimină după index.
  • Count returnează numărul curent de elemente (nu capacitatea internă).
  • List<T> poate fi inițializată direct: var numere = new List<int> { 1, 2, 3, 4, 5 };

Dictionary<TKey, TValue>

Dictionary<TKey, TValue> este o colecție de perechi cheie-valoare. Fiecare cheie este unică și permite accesul rapid (O(1)) la valoarea asociată. Este ideală pentru căutări rapide și mapări între date.

// Crearea unui dicționar
Dictionary<string, int> varste = new Dictionary<string, int>();

// Adăugare perechi cheie-valoare
varste["Ana"] = 25;
varste["Ion"] = 30;
varste.Add("Maria", 28);

// Accesare valori
int varstaAnei = varste["Ana"]; // 25

// Verificare existență cheie
if (varste.ContainsKey("Ion")) {
  Console.WriteLine("Ion exista in dictionar.");
}

// TryGetValue – acces sigur fără excepții
if (varste.TryGetValue("Ana", out int rezultat)) {
  Console.WriteLine($"Varsta: {rezultat}");
}

// Iterare prin dicționar
foreach (KeyValuePair<string, int> pereche in varste) {
  Console.WriteLine($"{pereche.Key}: {pereche.Value}");
}
  • Cheile trebuie să fie unice: adăugarea unei chei duplicate aruncă ArgumentException.
  • Accesul prin index (dict["cheie"]) aruncă KeyNotFoundException dacă cheia nu există.
  • TryGetValue este metoda recomandată pentru acces sigur, returnând true/false.
  • Cheile pot fi orice tip care implementează corect GetHashCode() și Equals().

Queue<T> și Stack<T>

Queue<T> (coada) respectă principiul FIFO (First In, First Out) – primul element adăugat este primul care iese. Stack<T> (stiva) respectă principiul LIFO (Last In, First Out) – ultimul element adăugat este primul care iese.

// Queue (coadă) – FIFO
Queue<string> coada = new Queue<string>();
coada.Enqueue("Primul");
coada.Enqueue("Al doilea");
coada.Enqueue("Al treilea");

string scos = coada.Dequeue(); // "Primul"
string urmatorul = coada.Peek(); // "Al doilea" (doar vizualizare)

// Stack (stivă) – LIFO
Stack<int> stiva = new Stack<int>();
stiva.Push(10);
stiva.Push(20);
stiva.Push(30);

int extras = stiva.Pop(); // 30 (ultimul adăugat)
int varf = stiva.Peek();  // 20 (doar vizualizare)
  • Queue: Enqueue() adaugă la sfârșit, Dequeue() extrage de la început, Peek() vizualizează primul element.
  • Stack: Push() adaugă în vârf, Pop() extrage din vârf, Peek() vizualizează vârful.
  • Ambele au proprietatea Count și metoda Clear() pentru golire.
  • Utilizări tipice: Queue pentru procesare în ordine (printare, mesaje); Stack pentru undo/redo, evaluare expresii.

Tipuri generice (Generics)

Genericele permit definirea de clase, metode și interfețe cu parametri de tip. Acestea oferă reutilizare maximă a codului, siguranța tipurilor la compilare și performanță superioară (evită boxing/unboxing-ul).

// Clasă generică
class Cutie<T> {
  public T Continut { get; set; }

  public void AfiseazaContinut() {
    Console.WriteLine($"Continut: {Continut}");
  }
}

// Utilizare cu tipuri diferite
Cutie<int> cutieNumere = new Cutie<int>();
cutieNumere.Continut = 42;

Cutie<string> cutieText = new Cutie<string>();
cutieText.Continut = "Hello generice!";
// Constrângeri pe tipuri generice
class Repository<T> where T : class {
  // T trebuie să fie un tip referință (clasă)
}

class Comparabil<T> where T : IComparable<T> {
  // T trebuie să implementeze IComparable
}

// Metodă generică
static void Swap<T>(ref T a, ref T b) {
  T temp = a;
  a = b;
  b = temp;
}
  • Parametrii de tip sunt specificați între < >; prin convenție se folosesc T, TKey, TValue.
  • Constrângerile (where T : ...) restricționează tipurile acceptate: class, struct, new(), clase de bază, interfețe.
  • Avantaje: reutilizare fără duplicare de cod, siguranța tipurilor, performanță (fără boxing).
  • Colecțiile generice (List<T>, Dictionary<TKey,TValue>) sunt implementate folosind generice.

IEnumerable<T> și iterația

IEnumerable<T> este interfața fundamentală pentru iterație în .NET. Orice colecție care o implementează poate fi parcursă cu foreach. Aceasta definește metoda GetEnumerator() care returnează un obiect IEnumerator<T>.

// IEnumerable permite iterare cu foreach
IEnumerable<int> numere = new List<int> { 1, 2, 3, 4, 5 };

foreach (int numar in numere) {
  Console.WriteLine(numar);
}

// Implementare personalizată IEnumerable
class NumerePare : IEnumerable<int> {
  private int maxim;
  public NumerePare(int maxim) { this.maxim = maxim; }

  public IEnumerator<int> GetEnumerator() {
    for (int i = 0; i <= maxim; i += 2) {
      yield return i;
    }
  }
}
  • IEnumerable<T> permite doar iterare forward, fără a modifica colecția în timpul iterației.
  • yield return simplifică crearea de iteratori, returnând câte un element pe rând fără a construi o colecție completă.
  • LINQ se bazează pe IEnumerable<T>, oferind metode de extensie precum Where(), Select(), OrderBy().
  • Deferred execution: interogările pe IEnumerable<T> nu se execută până la iterația efectivă (ex: cu foreach sau ToList()).
