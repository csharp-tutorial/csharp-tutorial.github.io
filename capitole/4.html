Capitolul 4

Metode și funcții

Declarare, parametri, return, supraîncărcare și metode statice

Declararea metodelor

O metodă (numită și funcție) este un bloc de cod cu un nume, care poate fi apelat ori de câte ori ai nevoie de acea funcționalitate. Metodele ajută la organizarea codului, evitarea repetiției și creșterea lizibilității.

// Sintaxa de bază a unei metode
static void Salut() {
  Console.WriteLine("Bun venit în C#!");
}

// Apelarea metodei
Salut(); // afișează: Bun venit în C#!
  • Tipul returnat – ce fel de valoare întoarce metoda (void = nu returnează nimic, int, string etc.).
  • Numele metodei – ar trebui să fie sugestiv, de obicei un verb (ex: CalculeazaSuma, AfiseazaMesaj).
  • Parametrii – opționali, puși între paranteze; definesc ce date primește metoda.
  • Corpul metodei – între acolade { }, conține instrucțiunile care se execută la apelare.

Parametrii metodelor

Parametrii sunt valorile pe care le trimiți unei metode pentru a lucra cu ele. În C#, parametrii pot fi transmiși în mai multe moduri:

// Parametru by value (implicit) – se trimite o copie
static void Dubleaza(int x) {
  x = x * 2; // modifică doar copia locală
}

// Parametru by reference (ref) – modifică variabila originală
static void DubleazaRef(ref int x) {
  x = x * 2; // modifică direct variabila din apelant
}

// Parametru de ieșire (out) – returnează o valoare prin parametru
static void Calculeaza(int a, int b, out int suma) {
  suma = a + b;
}
  • By value (implicit) – metoda primește o copie; valoarea originală rămâne neschimbată.
  • ref – transmite referința către variabilă; modificările sunt vizibile în afara metodei. Variabila trebuie inițializată înainte de apel.
  • out – similar cu ref, dar variabila nu trebuie inițializată înainte; metoda este obligată să îi atribuie o valoare.
  • params – permite un număr variabil de argumente: static int Suma(params int[] numere).

Instrucțiunea return

return trimite o valoare înapoi către codul care a apelat metoda și încheie imediat execuția acesteia. O metodă poate returna un singur tip de date (sau nimic, dacă e void).

// Metodă care returnează un int
static int Aduna(int a, int b) {
  return a + b;
}

// Metodă care returnează un string
static string FormatareNume(string prenume, string nume) {
  return $"{nume}, {prenume}";
}

// Utilizare
int rezultat = Aduna(5, 3); // rezultat = 8
string numeComplet = FormatareNume("Ion", "Popescu"); // "Popescu, Ion"
  • Tipul returnat trebuie să corespundă cu cel declarat în semnătura metodei.
  • return poate fi folosit și în metode void (fără valoare) pentru a ieși mai devreme din metodă.
  • Expresii lambda – pentru metode foarte simple, poți folosi => : static int Dublu(int x) => x * 2;

Supraîncărcarea metodelor (Overloading)

Supraîncărcarea (overloading) îți permite să definești mai multe metode cu același nume, dar cu parametri diferiți (număr, tip sau ordine). Compilatorul alege automat versiunea potrivită în funcție de argumentele trimise.

// Trei versiuni ale aceleiași metode "Afiseaza"
static void Afiseaza(string text) {
  Console.WriteLine($"Text: {text}");
}

static void Afiseaza(int numar) {
  Console.WriteLine($"Numar: {numar}");
}

static void Afiseaza(string text, int numar) {
  Console.WriteLine($"{text}: {numar}");
}

// Apeluri – compilatorul știe pe care să o aleagă
Afiseaza("Salut");        // prima metodă
Afiseaza(42);              // a doua metodă
Afiseaza("Varsta", 25);   // a treia metodă
  • Regula de bază: Semnătura metodei (nume + tipurile parametrilor) trebuie să fie unică.
  • Tipul returnat NU contează pentru overloading – două metode cu aceiași parametri dar tip returnat diferit vor genera eroare.
  • Utilitate: Face codul mai intuitiv – poți apela aceeași metodă „logică" cu tipuri diferite de date.

Metode statice

O metodă statică aparține clasei, nu unei instanțe (obiect). Se apelează direct prin numele clasei, fără a fi nevoie să creezi un obiect. Metodele statice sunt perfecte pentru funcționalități independente, utilitare.

// Exemplu de metodă statică într-o clasă
class Calculator {
  public static int Patrat(int x) {
    return x * x;
  }
}

// Apelare – direct prin numele clasei
int rezultat = Calculator.Patrat(5); // 25

// Exemple din biblioteca .NET
Math.Sqrt(16);       // 4.0
String.IsNullOrEmpty(s); // true/false
Console.WriteLine(...);  // toate metodele Console sunt statice
  • Avantaje: Nu consumi memorie pentru instanțe; acces rapid la funcționalități generale.
  • Limitări: Metodele statice nu pot accesa membri non-statici (câmpuri, proprietăți) ai clasei.
  • Cuvântul cheie static se pune înaintea tipului returnat în declarație.
  • Clase statice: Poți declara o întreagă clasă ca static (ex: static class Utilitare { }) – toți membrii ei trebuie să fie statici.
