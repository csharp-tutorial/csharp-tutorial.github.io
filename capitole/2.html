Sintaxa de bază

Variabile, tipuri de date, operatori, conversii și citirea de la tastatură

Variabile și constante

O variabilă este un spațiu de memorie numit care stochează date ce pot fi modificate în timpul execuției. O constantă (declarată cu const) este o valoare fixă, care nu poate fi schimbată după inițializare.

  • Declarare variabilă: int varsta = 25; – tipul, numele și valoarea inițială.
  • Constantă: const double PI = 3.14159; – valoarea rămâne neschimbată pe tot parcursul programului.
  • var: C# poate deduce automat tipul: var nume = "Ana"; – compilatorul știe că e string.
  • Reguli de numire: Numele variabilelor încep cu literă sau underscore, nu conțin spații și sunt case-sensitive.

Tipuri de date

C# este un limbaj puternic tipizat, ceea ce înseamnă că fiecare variabilă trebuie să aibă un tip bine definit. Iată principalele tipuri:

  • int – numere întregi (ex: 42, -10).
  • double – numere cu zecimale (ex: 3.14, -0.5).
  • char – un singur caracter (ex: 'A', '9').
  • string – șir de caractere (ex: "Hello").
  • bool – valori logice: true sau false.

Operatori

Operatorii sunt simboluri care efectuează operații asupra variabilelor și valorilor:

  • Aritmetici: +, -, *, /, % (modulo – restul împărțirii).
  • Relaționali: ==, !=, <, >, <=, >= – returnează true/false.
  • Logici: && (AND), || (OR), ! (NOT) – combinați condiții boolean.
  • Atribuire: =, +=, -=, *= etc.

Conversii de tip

Transformarea unei valori dintr-un tip în altul poate fi:

  • Implicită – când nu există risc de pierdere de date (ex: int → double).
  • Explicită (cast) – când pierderea e posibilă și programatorul își asumă: double x = 3.14; int y = (int)x; // y = 3.
  • Metode de conversie: int.Parse("42"), Convert.ToInt32("42"), .ToString().

Citire și scriere în consolă

Interacțiunea de bază cu utilizatorul se face prin:

  • Scriere: Console.WriteLine("Text"); – afișează text și trece la linie nouă.
  • Scriere fără linie nouă: Console.Write("Text");.
  • Citire: string input = Console.ReadLine(); – citește tot textul introdus până la Enter.
  • Citire caracter: Console.ReadKey() – citește o singură tastă apăsată.
