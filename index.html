Ce este C#?

C# este un limbaj de programare modern, orientat pe obiecte (OOP) și puternic tipizat. Are o sintaxă clară și curată, derivată din familia de limbaje C, fiind foarte similar ca structură cu Java sau C++. A fost conceput de la bun început pentru a rula pe platforma .NET, un mediu de execuție uriaș care îi oferă mii de biblioteci predefinite, făcând scrierea codului mult mai rapidă și mai sigură (de exemplu, gestionează automat memoria prin procesul de Garbage Collection).

De cine și când a fost creat?

  1. Creator: Limbajul a fost creat de compania Microsoft. Echipa de dezvoltare a fost condusă de inginerul danez Anders Hejlsberg, o figură legendară în programare (el fiind și creatorul Turbo Pascal, Delphi, iar mai târziu, al TypeScript-ului).
  2. Lansare: Dezvoltarea sa a început la finalul anilor '90 sub numele de cod „Cool” (C-like Object Oriented Language). A fost redenumit în C# și anunțat oficial în anul 2000, fiind lansat publicului larg în 2002, odată cu prima versiune a platformei .NET.

Pentru ce este utilizat?

C# este extrem de versatil (este un limbaj de tip general-purpose), ceea ce înseamnă că poți construi aproape orice cu el:

  1. Dezvoltare de Jocuri (Gamedev): Este limbajul principal folosit în Unity, cel mai popular motor pentru crearea de jocuri video 2D, 3D, AR (Realitate Augmentată) și VR (Realitate Virtuală), atât pentru PC/console, cât și pentru mobile.
  2. Aplicații Web (Backend): Prin intermediul framework-ului ASP.NET Core, C# este folosit la scară largă pentru a construi site-uri web extrem de rapide, sigure și scalabile, dar și API-uri (partea din spate a unei aplicații).
  3. Aplicații Desktop pentru Windows: Rămâne limbajul standard pentru dezvoltarea de software pe sistemele de operare Windows (folosind tehnologii precum WPF, Windows Forms sau, mai nou, WinUI).
  4. Aplicații Mobile (Cross-platform): Cu ajutorul tehnologiilor precum .NET MAUI (fostul Xamarin), poți scrie cod o singură dată în C# și îl poți rula atât ca aplicație nativă de Android, cât și de iOS.
  5. Software de Enterprise și Cloud: Este o alegere de top pentru corporațiile mari care au nevoie de sisteme de business complexe, fiabile și perfect integrate cu serviciile cloud (în special cu Microsoft Azure).

Ce ne trebuie pentru a utiliza C#?

Pasul 1

Descarcă și instalează .NET SDK de pe site-ul oficial Microsoft. Asigură-te că alegi versiunea potrivită pentru sistemul tău de operare.

Pasul 2

Alege un editor de cod. Recomand Visual Studio Community (gratuit) sau Visual Studio Code cu extensia C# pentru o experiență completă.

Pasul 3

Deschide terminalul și tastează dotnet new console pentru a crea primul tău proiect C#. Apoi scrie dotnet run pentru a-l executa.
